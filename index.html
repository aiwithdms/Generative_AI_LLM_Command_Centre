RESPONSE ANALYSIS

Inspect more than the text

Capture model ID, response content, usage/token fields when returned, finish reason, timing, errors, and request settings.

Never place API keys in browser HTML, client-side JavaScript, screenshots, or source control. Use environment variables and a server-side proxy.

OBSERVE

Quality & instruction following

Check factuality, missing information, format adherence, reasoning transparency, and whether the answer fits the task.

MEASURE

Tokens, latency & cost

CONTROL

Keep prompt, source data, task requirements, and evaluation rubric constant. Note provider-specific settings and run more than once.
